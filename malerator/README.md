# Meal Rater 🍽

Meal Rater is a Django-based web app that allows users to view meals and rate them.

## Features
- View meals list
- Add ratings to meals
- User authentication (Token-based)

## Technologies
- Django REST Framework
- SQLite

## How to Run

```bash
# Install dependencies
pip install -r requirements.txt

# Run migrations
python manage.py migrate

# Start the server
python manage.py runserver
